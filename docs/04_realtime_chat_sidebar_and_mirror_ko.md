## 1. 개요 및 레이아웃 구조

v4.8.0에서는 모바일용 드로어(Drawer) 형태의 숨겨진 채팅창에서 벗어나, 대시보드 화면 우측에 상시 고정되는 **도킹 실시간 분할 사이드바(`.docked-chat-sidebar`)**를 구축했습니다.

```
+-------------------------------------------------------------+------------------------------------+
|  [CHZZK] 치지직 대규모 추첨 & 룰렛 & 배틀    [상태 HUD]     |  💬 실시간 시청자 채팅  🔴 LIVE 5  |
+-------------------------------------------------------------+------------------------------------+
|                                                             |  [전체]   [⭐ 구독자]   [🧀 후원]   |
|  [ 메인 작업대 ]                                             |  🔍 닉네임/메시지 실시간 검색...    |
|                                                             +------------------------------------+
|   - 🎟️ 시청자 대규모 추첨기                                  |  (시청자 채팅 피드 아이템)         |
|   - 🎰 비주얼 룰렛 엔진                                     |  - 닉네임 / 시간 / 뱃지            |
|   - 📊 실시간 투표 차트                                     |  - 채팅 메시지 텍스트              |
|   - 🎮 포켓몬 배틀 & 퀴즈 쇼 & 찌리리공                     |  - 치즈 후원 강조 골드 박스        |
|                                                             |                                    |
+-------------------------------------------------------------+------------------------------------+
```

## 2. 도킹 채팅창 주요 기능

### 2.1 3단 탭 실시간 필터링
- **전체 (`all`)**: 유입되는 모든 채팅 메시지 실시간 노출.
- **⭐ 구독자 (`sub`)**: 치지직 채널 구독 배지를 보유한 시청자의 채팅만 필터링.
- **🧀 후원자 (`cheese`)**: 치즈 후원 메시지(금액 포함)만 별도로 모아보기.

### 2.2 실시간 피드 내 검색 (In-feed Search)
- 검색창에 닉네임 또는 메시지 키워드를 입력하면, 수신된 채팅 목록 중에서 일치하는 항목만 실시간으로 즉시 필터링 표시.

### 2.3 스마트 스크롤 락 & 플로팅 알림 (`chatNewMsgFloatingBtn`)
- 사용자가 지난 채팅을 확인하기 위해 마우스 휠을 올려 상단으로 스크롤하면, 새 메시지가 와도 뷰포트가 강제로 내려가지 않고 고정됩니다.
- 스크롤이 바닥에서 벗어나면 우측 하단에 **`[ ⬇️ 새 메시지 ]`** 플로팅 버튼이 표시되며, 클릭 시 최하단으로 즉시 점프합니다.
- 하단 체크박스 `[✓] 자동 스크롤`을 통해 자동 스크롤 강제 여부를 켜고 끌 수 있습니다.

## 3. 독립 팝아웃 창 미러링 (Popout Window Mirroring)

듀얼 모니터 환경에서 OBS 방송 화면이나 보조 모니터에 채팅창만 따로 분리하여 띄울 수 있는 독립 팝아웃 기능을 지원합니다.

### 동작 원리:
1. `openChatPopoutWindow()` 호출 시 `window.open('', 'ChzzkLiveChatPopout', 'width=420,height=750')` 실행.
2. 팝아웃 윈도우에 고대비 다크 테마 HTML/CSS 템플릿 주입.
3. 웹소켓으로 새 채팅(`addChatToFeed`)이 수신될 때마다, 팝아웃 창이 열려 있는지(`popoutWindowRef && !popoutWindowRef.closed`) 확인 후 팝아웃 창의 DOM(`#feed`)에 실시간 미러링 추가.
