## 🌟 주요 변경 사항 (What's New in v4.8.4)

### 1. 💬 실시간 채팅창 오버레이 (Floating Overlay Drawer) 전면 개편
- **메인 컨텐츠 밀림/축소 원천 방지**:
  - 기존에 채팅창이 열릴 때 flexbox 레이아웃으로 인해 메인 게임 화면(포켓몬 배틀, 룰렛, 추첨기 등)이 좌측으로 380px만큼 밀려나거나 찌그러지던 문제를 완벽히 해결했습니다.
  - 메인 레이아웃(`.app-main-content`)은 채팅창 개폐 여부와 무관하게 항상 **100% 정중앙 풀 와이드(너비/좌표 변동 0.00px)**를 유지합니다.
- **부드러운 하드웨어 가속 슬라이드 인(Slide-in)**:
  - 채팅창(`#dockedChatSidebar`)이 화면 우측 상단 레이어로 자연스럽게 떠오르며 슬라이드되는 오버레이 드로어 구조로 전환되었습니다.
- **일체형 플로팅 토글 탭 핸들**:
  - 화면 우측 플로팅 버튼(`#floatingChatTabBtn`)이 채팅창의 슬라이드 모션과 동기화되어, 채팅창이 열리면 **채팅창 좌측 모서리에 일체형 닫기 핸들(`✕ 닫기`)**로 매끄럽게 결합됩니다.
  - 언제든 화면 우측 핸들, 채팅창 내부 `✕` 버튼, 또는 상단 헤더의 `💬 실시간 채팅창` 버튼으로 열고 닫을 수 있습니다.

### 2. 👆 채팅창 닉네임 원클릭 시청자 채팅 내역 & 실시간 추적 모달 연동
- **채팅창 닉네임 클릭 지원**:
  - 우측 실시간 도킹/오버레이 채팅창, 모바일 채팅 드로어, 팝아웃 새 창에서 시청자 닉네임을 클릭하면 해당 시청자의 **실시간 채팅 내역 & 추적 모달(`userChatModal`)**이 즉시 열립니다.
- **스마트 3단계 시청자 매칭 알고리즘 (`openUserChatByNickOrUid`)**:
  1. **고유 UID 1순위 매칭**: 수집된 고유 `uid`를 기준으로 참가자 맵(`participants`) 또는 당첨자 목록(`drawnWinners`) 즉시 조회.
  2. **닉네임 2순위 역추적**: 비회원이나 UID 누락 시 참가자 목록 및 누적 채팅 기록(`userChatHistory`)에서 닉네임으로 자동 역추적 매칭.
  3. **미등록 시청자 임시 프로필 생성**: 방송 시작 직후나 최초 채팅자라도 임시 프로필을 생성하여 모달이 100% 정상 작동하도록 보장.
- **실시간 라이브 추적 & TTS 음성 낭독 완벽 연동**:
  - 모달이 열려 있는 상태에서 해당 시청자가 방송 채팅을 입력하면 모달 내역에 `🔴 LIVE NEW` 뱃지와 함께 실시간으로 자동 추가됩니다.
  - 실시간 TTS 음성 출력 스위치가 켜져 있으면 새로 입력된 채팅을 설정된 음성 속도/톤으로 즉시 읽어줍니다.

### 3. 🎨 닉네임 시각 피드백 (Hover Affordance) & 역할별 테마 컬러
- 채팅창 내 닉네임에 마우스를 올렸을 때 클릭 가능한 상호작용임을 직관적으로 인지할 수 있도록 시각 피드백을 적용했습니다:
  - 마우스 손가락 커서(`cursor: pointer`)
  - 부드러운 네온 하이라이트 알약(Pill) 배경 및 밑줄 효과
  - 마우스 오버 시 `[닉네임] 시청자 채팅 추적 및 상세 정보 열기` 툴팁 안내
- 시청자 역할별 고유 테마 컬러 매칭:
  - **일반 시청자**: 치지직 네온 그린 (`#00ffa3`)
  - **구독자**: 바이올렛 퍼플 (`#c084fc`)
  - **치즈 후원자**: 럭셔리 골드 (`#ffd700`)

### 4. 🛠️ 방송 라이브(LIVE) 상태 동기화 & 방송 변경 모달 중복 버그 수정
- **연결 중(connecting) 데이터 보존 및 라이브 상태 정상 출력**: 웹소켓 접속 시도 중 `setStatus`에 의해 라이브 상태 및 채널 프로필 이미지가 초기화되던 버그를 해결하여, 방송 접속 시 `🔴 LIVE`, 실제 시청자 수, 스트리머 원형 아바타가 정상적으로 표시됩니다.
- **[방송 변경] 클릭 시 구버전 모달 중복 출력 제거**: 상단 칩 버튼의 중복 리스너를 정리하여 구버전 팝업 창 없이 최신 Welcome 검색 화면만 단독으로 열리도록 일원화했습니다.
- **실시간 라이브 상태 폴링 주기 최적화**: 접속 2.5초 후 1차 자동 갱신 및 매 15초마다 최신 라이브 상태를 자동 감지하도록 폴링을 강화했습니다.
