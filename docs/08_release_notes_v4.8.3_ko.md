# 🚀 v4.8.3 릴리즈 노트 (Release Notes)

- **배포 버전**: v4.8.3
- **배포 일자**: 2026-09-06
- **주요 테마**: 스트리머 비밀 조작 모드(독립 팝업 제어기 + 방송 화면 자동 블라인드 + 키보드 단축키 엔진), 기술/교체 선택 토글 및 취소 지원, 100ms 타이머 DOM 분리를 통한 클릭 안정성 확보, UI 편의성 개선

---

## 🌟 주요 변경 사항 (What's New in v4.8.3)

### 1. 🎮 보조 모니터 전용 독립 팝업 제어기 (window.open)
- 스트리머 조작 패널의 **[ ↗️ 비밀 제어창 분리 ]** 버튼 클릭 (또는 단축키 **O**) 시 보조 모니터로 이동시킬 수 있는 독립 팝업 제어창이 열립니다.
- **실시간 양방향 동기화**:
  - 내 출전 포켓몬 스프라이트, 이름, 실시간 HP 바 / 텍스트, 타입, 지닌 도구 표시
  - 상대(시청자) 포켓몬 정보 및 **내 기술별 상성 배율 가이드** (2x 효과발군, 0.5x 반감, 0x 무효) 실시간 계산
  - **메가진화 네온 토글 버튼**: 원클릭 / Space 키로 장전 ON/OFF
  - **4대 기술 슬롯**: [Q], [W], [E], [R] 뱃지, 실시간 잔여 PP, 위력/명중
  - **팀원 교체 슬롯**: [1], [2] 뱃지, 생존 팀원 체력 상태 및 원클릭 교체
  - **실시간 카운트다운 타이머 바**: 메인 창 타이머와 100ms 단위 동기화

### 2. 🛡️ 제어창 분리 시 방송 화면 자동 블라인드 (Auto-Blind Privacy Mask)
- 제어창을 분리하는 순간 메인 방송 화면의 블라인드가 **자동으로 활성화(ON)**되어, 스트리머가 별도로 블라인드를 켜지 않아도 시청자 화면(OBS 캡처)의 기술 선택 덱이 즉시 보안 카드로 가려집니다.
- 시청자에게 마우스 커서의 호버링 위치나 기술명이 일절 노출되지 않아 방송 중 스포일러 및 스나이핑을 완벽 차단합니다.
- 메인 화면이나 제어창에서 언제든 [ 👁️ 방송 블라인드 ] 버튼이나 **B** 키로 블라인드를 다시 해제/토글할 수 있습니다.

### 3. ⌨️ 키보드 단축키 엔진 완비
- 방송 화면에서 마우스 커서를 전혀 움직이지 않고 키보드만으로 완전한 배틀 조작이 가능합니다:
  - **Q, W, E, R**: 1~4번 기술 선택
  - **Space / M**: 메가진화 장전 ON/OFF 토글
  - **1, 2**: 1~2번 대기 팀원으로 즉시 교체
  - **B**: 방송 화면 블라인드 ON/OFF 토글
  - **O**: 독립 비밀 제어창 열기
  - **X**: 발버둥 (모든 기술 PP 소진 시)
  - **Esc / Backspace**: 현재 선택된 행동 취소
  - 기절 후 교체 창에서도 1, 2 키로 후속 포켓몬 즉시 출전 선택 가능

### 4. 🔄 기술 및 교체 선택 토글 및 취소(Cancel) 완벽 지원
- **원클릭 선택 및 재클릭 취소**: 이미 선택된 기술 버튼이나 교체 카드를 **다시 한 번 누르면 선택이 즉시 취소(해제)**되어 대기 상태로 복귀합니다.
- **[✖️ 선택 취소 (Esc)] 전용 버튼**: 행동 선택 완료 시 상단 알림 영역에 취소 버튼이 나타나 원클릭 또는 Esc 키로 손쉽게 취소 가능합니다.
- 단축키 재입력(Q 선택 후 다시 Q)으로도 선택 해제가 지원됩니다.

### 5. ⚡ 100ms 타이머 주기와 기술 덱 DOM 분리 (클릭 씹힘 완벽 해결)
- 100ms 타이머 주기에서는 시간 텍스트와 게이지 바만 경량 갱신(updateStreamerControllerTimer)하도록 분리했습니다.
- 기술 버튼과 교체 카드 DOM이 카운트다운 도중 파괴 및 재생성되지 않고 안정적으로 유지되어, 마우스 클릭이 100% 즉각적으로 인식됩니다.

### 6. 🎨 UI 편의성 개선
- **플로팅 채팅창 토글 아이콘 4배 확대**: 채팅창 닫기 아이콘과 동일한 위치로 이동 및 크기를 4배로 확대하여 시인성과 클릭 편의성 극대화.
- **기절 후 교체 시 시청자 투표 가림 처리**: 시청자 포켓몬이 쓰러져 다음 포켓몬으로 교체할 때도 시청자 투표 수를 집계 중 카드(다음 출전 포켓몬 시청자 투표 집계 중)로 가려 심리전 보호.
