# 📋 치지직 인터랙티브 스튜디오 (Chzzk Interactive Studio) 제품 요구사항 정의서 (PRD)

- **문서 버전**: v4.8.0
- **작성일자**: 2026-09-03
- **프로젝트 상태**: Production Ready / Active Maintenance

---

## 1. 프로젝트 한 줄 정의

네이버 **치지직(CHZZK)** 라이브 방송과 웹소켓(WebSocket)으로 직접 연동되어, 방송 화면에 최적화된 **단독 시작 화면(스트리머 이름 검색 & 팔로워 순 정렬)**, **수천 명 단위 대규모 추첨**, **물리 기반 비주얼 룰렛**, **실시간 채팅/치즈 투표**, **포켓몬 3v3/1v1 턴제 배틀 & 4대 퀴즈 쇼**, **찌리리공 뒤집기**, 그리고 **도킹 실시간 채팅 사이드바**를 단일 Windows 실행 파일 및 웹 브라우저에서 무설치로 제공하는 올인원 방송 인터랙션 솔루션.

## 2. 제품 최종 형태 및 사용자 여정

`mermaid
graph TD
    A[앱 실행 / 웹 접속] --> B[단독 시작 화면: Welcome Landing Screen]
    B --> C{검색창 입력}
    C -->|실시간 타이핑 250ms| D[치지직 검색 프록시 API 호출]
    D --> E[팔로워 많은 순 내림차순 정렬]
    E --> F[스트리머 프로필 카드 노출]
    F -->|원클릭 선택| G[치지직 Live API & WebSocket 토큰 획득]
    G --> H[메인 작업대 자동 전환: App Workspace]
    H --> I[상단 헤더 HUD: 실시간 방송 상태 및 시청자 수]
    H --> J[우측 도킹 실시간 채팅창: 구독/치즈 필터 & 자동 스크롤]
    H --> K[중앙 4대 모드 탭: 추첨 / 룰렛 / 투표 / 미니게임]
`

### 핵심 사용자 경험 (UX):
1. **무설치 원클릭 실행**: 사용자는 복잡한 Python 환경 구축이나 외부 라이브러리 설치 없이 치지직추첨기.exe를 실행하면 즉시 브라우저 대시보드가 열립니다.
2. **몰입형 단독 시작 화면 (Welcome Screen)**:
   - 첫 진입 시 어지러운 설정 창 대신, 중앙의 대형 스마트 검색창이 사용자를 맞이합니다.
   - 복잡한 32자리 채널 ID나 URL을 몰라도 **스트리머 닉네임(예: 침착맨, 초승달, 풍월량, 랄로 등)**만 입력하면 즉시 검색됩니다.
   - 검색 버튼을 따로 누르지 않아도 **타이핑하는 순간(250ms 디바운스)** 아래에 팔로워 수가 가장 많은 공식 채널 순서로 카드가 나열됩니다.
   - 스트리머 카드를 클릭하면 1초 만에 방송 토큰을 발급받아 웹소켓에 연결되고 메인 작업대로 매끄럽게 전환됩니다.
3. **군더더기 없는 넓은 작업대**:
   - 상단 중복 방송 상태 바를 제거하여 추첨, 룰렛, 포켓몬 배틀 등 메인 작업 공간의 세로 시야를 최대로 확보했습니다.
   - 방송 상태 및 시청자 수, 방송 변경, 연결 종료는 최상단 헤더의 상태 칩에서 언제든 제어 가능합니다.
4. **상시 도킹 실시간 채팅 사이드바**:
   - 작업대 우측에 치지직 실시간 채팅창이 상시 고정되어, 방송 화면을 별도로 띄워두지 않아도 시청자들의 반응과 응모 채팅을 한눈에 확인할 수 있습니다.
   - 구독자 전용 채팅, 치즈 후원 채팅 필터링 및 키워드 검색, 원클릭 팝아웃 새 창 분리를 지원합니다.

## 3. 목표 사용자 (Target Audience)

- **치지직 라이브 스트리머**: 시청자 참여형 콘텐츠(구독자 추첨, 시청자 미션 룰렛, 토론 투표, 포켓몬 배틀/퀴즈)를 간편하게 진행하고자 하는 방송인.
- **방송 매니저 & 운영진**: 수천~수만 명의 채팅 중에서 공정하게 당첨자를 선별하고 엑셀(CSV)로 명단을 추출하여 리워드를 발송해야 하는 운영자.
- **치지직 시청자**: 별도의 앱 설치나 로그인 없이, 치지직 채팅창에 명령어(1, !응모, A1, 메가1 등)를 입력하는 것만으로 방송 화면의 게임과 추첨에 직접 참여하는 대중.

## 4. 핵심 기능 요구사항 (Functional Requirements)

### 4.1 온보딩 및 채널 검색 엔진
- **이름 기반 검색**: Chzzk Search API를 통한 채널명 실시간 쿼리.
- **팔로워 수 내림차순 정렬**: 동명이인 및 팬 채널 중 팔로워 수가 가장 많은 본 채널을 최상단 1순위로 배치 (ollowerCount desc).
- **실시간 디바운스 타이핑 검색**: 엔터나 버튼 클릭 없이 입력 즉시(250ms) 결과 노출.
- **19세 연령제한 방송 쿠키 지원**: NID_AUT / NID_SES 입력 아코디언 제공 및 자동 로컬 암호화 저장.
- **수동 오프라인 모드**: 방송 연결 없이 룰렛, 배틀, 퀴즈를 단독으로 테스트할 수 있는 오프라인 바이패스 지원.

### 4.2 시청자 대규모 추첨기 (Mega Raffle)
- **초고속 웹소켓 채팅 파싱**: 초당 수백 건의 채팅을 유실 없이 수집하고 유효 응모자를 실시간 집계.
- **세분화된 필터링 규칙**:
  - 전체 참여자 vs 지정 키워드 (단독 일치 / 포함 일치)
  - 구독자 필터 (구독 개월 수 조건 / 1티어, 2티어 지정)
  - 치즈 후원 필터 (최소 치즈 금액 및 등급 조건)
- **정밀 중복 방지 시스템**:
  - 동일인 1회 응모 보장 (UID 기준 고유 식별)
  - 다회차 추첨 시 이전 회차 당첨자 자동 제외 토글
  - 엑셀/CSV 블랙리스트 파일 업로드 제외
  - 수동 닉네임/UID 다중 제외
- **결과 추출**: 당첨 순위, 닉네임, UID, 구독 상태, 후원 금액을 포함한 커스텀 UTF-8 BOM CSV 내보내기.

### 4.3 비주얼 룰렛 (Visual Roulette Engine)
- **HTML5 Canvas 물리 엔진**: 가속, 등속, 현실적인 감속 물리 회전 및 화살표 틱 충돌 애니메이션.
- **웹 오디오 합성 사운드**: 외부 오디오 파일 다운로드 없이 브라우저 Web Audio API로 구현된 실감 나는 틱 소리 및 당첨 팡파레.
- **동적 항목 및 가중치 계산**: 각 항목별 확률 백분율 실시간 표시 및 프리셋 제공.
- **치즈 후원 자동 연동**: 방송 중 치즈 후원이 발생하면 룰렛 항목으로 자동 등록되어 미션 룰렛 진행 가능.

### 4.4 실시간 투표 (Real-time Live Poll)
- **실시간 다이내믹 게이지**: 시청자 채팅 번호(1, 2, 3 등)를 집계하여 실시간 득표율 게이지 바 애니메이션 렌더링.
- **치즈 가중치 투표**: 1치즈당 1표로 환산하는 후원 기반 투표 모드 지원.
- **원클릭 룰렛 전환**: 투표 득표율을 그대로 룰렛 확률로 전환하여 연계 방송 진행.

### 4.5 포켓몬 턴제 배틀 (Pokemon Battle Hub)
- **235마리 공식 데이터셋**: 1~9세대 인기 포켓몬 풀, 실전 종족값, 타입, 기술 및 지닌도구 152종 탑재.
- **배틀 모드**: 3v3 팀 엔트리 교체 배틀 & 1v1 단판 에이스 배틀.
- **시청자 집단지성 투표**: 채팅창 투표를 통해 시청자 다수결로 기술 선택 및 교체 진행.
- **배틀 로직**: 18개 상성 타입 차트, 자속 보정(STAB 1.5배), 급소, 명중률, 랭크업/다운, 메가진화(46종), 기술별 PP 시스템.

### 4.6 포켓몬 퀴즈 쇼 (Pokemon Quiz Show)
- **4대 퀴즈 유형**: 실루엣 퀴즈, 공식 도감 설명 퀴즈, 실제 게임 울음소리 퀴즈, 3단 단서 퀴즈.
- **3단계 수동 힌트 시스템**: 1단계 속성 타입 ➡️ 2단계 분류/출신 세대 ➡️ 3단계 한글 초성.
- **스트리머 답안 지연 채점**: 스트리머 답안 제출 후 즉시 채점하지 않고 타이머 만료 시 시청자 집단지성 투표와 동시 채점.

### 4.7 찌리리공 뒤집기 (Voltorb Flip)
- **5×5 두뇌 지뢰찾기**: 숨겨진 2배/3배 코인과 찌리리공(폭탄)의 위치를 추리하는 스트리머 vs 시청자 대결.
- **대결 포맷**: 단판, 3판 2선승제(BO3), 5판 3선승제(BO5), 7판 4선승제(BO7).

### 4.8 도킹 실시간 채팅 사이드바
- **상시 2열 분할 레이아웃**: 좌측 작업대, 우측 실시간 채팅창.
- **실시간 메시지 필터**: 전체 / ⭐구독자 / 🧀후원자 전용 필터 탭.
- **스마트 스크롤 락**: 과거 채팅을 확인하기 위해 스크롤을 올리면 자동 스크롤이 일시 정지되며, [⬇️ 최신 메시지] 플로팅 버튼 제공.
- **독립 창 분리 (Popout)**: 듀얼 모니터 사용 스트리머를 위한 독립 팝아웃 윈도우 미러링.

## 5. 비목표 및 시스템 경계 (Non-Goals & Boundaries)

- **비인가 네이버 계정 해킹/크래킹 미지원**: 19세 방송 접근은 사용자가 직접 브라우저에서 확인한 본인의 합법적인 세션 쿠키(NID_AUT, NID_SES)만을 매개변수로 사용하며, 비밀번호를 탈취하거나 크래킹하지 않습니다.
- **채팅 조작 및 매크로 미지원**: 시청자 채팅창에 봇 메시지를 대량 발송하거나 도배하는 스팸 기능은 일체 포함하지 않습니다.
- **로컬 독립성 유지**: 사용자 데이터, 추첨 결과, 쿠키 정보는 외부 제3자 서버로 전송되지 않으며, 사용자 로컬 컴퓨터 브라우저의 localStorage 및 메모리에만 보관됩니다.

## 6. 품질 및 안정성 목표

- **동시 처리량**: 초당 500건 이상의 고속 채팅 스트림에서도 UI 프리징이나 프레임 드랍 없이 부드러운 렌더링 유지.
- **네트워크 복원력**: 치지직 웹소켓 세션 끊김 시 최대 5회 자동 지수 백오프 재연결.
- **호환성**: Chrome, Edge, Whale 등 Chromium 계열 최신 브라우저 100% 호환 및 Windows 10/11 x64 단일 실행 파일 지원.
