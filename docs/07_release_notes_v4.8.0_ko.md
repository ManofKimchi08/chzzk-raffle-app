# 🚀 v4.8.0 릴리즈 노트 (Release Notes)

- **배포 버전**: v4.8.0
- **배포 일자**: 2026-09-03
- **주요 테마**: 단독 시작 화면(Welcome Screen) 도입, 팔로워 순 실시간 채널 검색, 상단 바 정리 및 작업대 공간 극대화

---

## 🌟 주요 변경 사항 (What's New in v4.8.0)

### 1. 🎨 몰입형 단독 시작 화면 (Welcome Landing Screen) 신설
- 앱 첫 실행 시 복잡한 추첨/게임 작업대 대신, 깔끔하고 직관적인 **단독 온보딩 시작 화면**이 먼저 나타납니다.
- 중앙 대형 스마트 검색창을 통해 누구나 1초 만에 원하는 방송을 찾고 연결할 수 있습니다.
- 방송에 연결하지 않고 룰렛, 배틀, 퀴즈를 테스트해볼 수 있는 **`[ ➡️ 방송 연결 없이 오프라인 둘러보기 ]`** 모드를 지원합니다.

### 2. 🔍 스트리머 이름 실시간 검색 & 팔로워 많은 순 자동 정렬
- 기존 32자리 고유 ID나 URL 복사 없이, **스트리머 닉네임(예: `침착맨`, `초승달`, `풍월량`, `우왁굳` 등)**만 입력해도 즉시 검색됩니다.
- 검색 결과는 동명이인이나 팬 계정 대신 **팔로워 수가 가장 많은 공식 채널이 최상단 1순위로 자동 정렬**됩니다.
- 프로필 아바타, 닉네임, 치지직 인증 마크(`✓`), 생방송 여부(`🔴 LIVE` / `⚪ OFFLINE`), 팔로워 수(`32.4만명`)가 상세히 표시됩니다.

### 3. ⚡ 검색 버튼 클릭 없는 타이핑 즉시 자동 검색 (250ms Debounced Search)
- 시작 화면에서 스트리머 이름을 타이핑하는 즉시, 250ms 후 자동으로 실시간 검색 결과가 아래에 부드럽게 펼쳐집니다.
- 불필요한 마우스 클릭과 엔터 입력을 줄여 탐색 속도를 비약적으로 향상시켰습니다.

### 4. 🗑️ 상단 중복 방송 상태 바 제거 및 작업대 시야 극대화
- 헤더 아래 자리를 차지하고 있던 중복 방송 연결 바를 완전히 제거했습니다.
- 작업대 세로 여백이 대폭 확보되어 **메인 추첨/룰렛/배틀 영역과 우측 실시간 채팅창이 훨씬 시원하고 넓게 표시**됩니다.
- 방송 상태 및 시청자 수, `[ 📡 방송 변경 ]`, `[ 🛑 종료 ]` 기능은 상단 헤더 HUD에 일원화되었습니다.

### 5. 📚 엔터프라이즈급 상세 공식 문서 (`docs/`) 체계 구축
- PRD 요구사항 정의서, 아키텍처 및 프로토콜 명세서, 검색 엔진 설계서, 도킹 채팅창 명세서, 포켓몬 게임 엔진 명세서, 빌드 가이드 등 7종의 공식 기술 문서를 체계적으로 정리하여 `docs/` 폴더에 수록했습니다.

---

## 🛠️ 버그 수정 및 안정화
- **연결 파이프라인 복구**: 채널 선택 후 토큰 요청 및 웹소켓 연결 진입 함수(`startConnectionFlow`) 호출 누락 문제 수정.
- **불필요한 추천 검색 칩 제거**: 사용자 피드백을 수용하여 시작 화면 하단 추천 칩을 정리.
- **채팅 사이드바 실시간 동기화**: 작업대 전환 후에도 실시간 채팅 사이드바 피드가 끊김 없이 수신되도록 개선.
